## AI Assistant Overview

ChatGPT works as a dialogue: you describe a task, it answers, and you refine the answer through follow-up turns. The model keeps the current thread in context, so corrections accumulate instead of starting over. Output is plain text, which makes it portable into any editor.

People use it to outline articles, summarise long documents, translate a paragraph, debug a function, or rewrite a message in a different tone. ChatGPT features that come up most are file upload, custom instructions, and voice input. A ChatGPT app or web session is often the first place a task gets drafted now.

## Getting Started Playbook

Sign in, open a new thread, and state the task in one sentence with the audience and length you need. Attach any source document rather than pasting fragments. Set custom instructions once so tone and formatting rules stop being repeated.

Ask for a second version with a different structure and compare them. Read ChatGPT reviews about limits before paying, and check ChatGPT pricing if you need longer context or more usage. Keep a note of prompts that worked, since reusable prompts save the most time.
